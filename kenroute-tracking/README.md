# KenRoute Passenger Tracking (track.kenroute.in)

Passenger-facing live bus tracking website.

- React 19 + Vite + TypeScript
- Leaflet + OpenStreetMap (no Google Maps)
- socket.io-client for realtime GPS from the existing KenRoute backend

## Setup

```bash
cp .env.example .env
npm install
npm run dev
```

## Environment

| Variable | Purpose |
| --- | --- |
| `VITE_API_URL` | KenRoute API base, e.g. `https://api.kenroute.in/api/v1` |
| `VITE_SOCKET_URL` | KenRoute Socket.IO origin, e.g. `https://api.kenroute.in` |

## Usage

Passengers enter a PNR or mobile number, receive a short-lived tracking token from
`POST /api/v1/tracking/lookup`, then the page polls `GET /api/v1/tracking/location` and
subscribes to the existing trip room over Socket.IO for live updates.

The secure link format is `/t/<tracking-token>` — tokens are generated by the backend,
never by the browser.

## Flow

Conductor phone (real GPS) → `POST /conductor/trips/:id/location` → backend persists
`TripLocation` → Socket.IO room `trip:{tripId}` emits `location` → this page moves the
Leaflet bus marker.
